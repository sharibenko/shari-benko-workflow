# Agent instructions

- Follow CONTRIBUTING.md. Use a short-lived `codex/<description>` branch and a pull request after the initial repository bootstrap.
- Keep changes focused; avoid unrelated refactors, new frameworks, and dependencies without a concrete need.
- Run `npm run check` and `npm test` before reporting completion. Report any checks you cannot run.
- Preserve resume facts and collaborators' roles. Ask about material content ambiguities; never invent achievements or metrics.
- Never copy application tracking, recruiter notes, secrets, or confidential employer artifacts into this repository.
- A README or workflow file does not enforce GitHub branch rules. Distinguish documented policy from settings confirmed active on GitHub.
